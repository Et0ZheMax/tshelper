# Безопасность

Не публикуйте сведения об уязвимостях в открытых issues. Передайте владельцу репозитория описание, версию, сценарий воспроизведения и оценку влияния через приватный канал GitHub.

Конфигурации, пользовательские базы, токены GLPI/FreePBX, SSH-ключи и DPAPI-файлы не должны попадать в Git. Приложение хранит рабочие данные в `%APPDATA%\TSHelper`, а секреты — в Windows Credential Manager или защищённом DPAPI-файле.

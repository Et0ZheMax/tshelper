# TSHelper GLPI Inventory Bridge 0.1.4

Отдельное read-only расширение для сверки карточек TSHelper с оборудованием GLPI 11 через текущую браузерную сессию. API-токены GLPI не нужны.

## Установка

1. Распакуйте архив расширения в постоянную папку.
2. Откройте страницу управления расширениями Yandex Browser/Chrome и включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. В TSHelper откройте **Инструменты → Скопировать токен интеграции**.
5. Откройте настройки расширения, вставьте токен и нажмите **Проверить**.
6. Авторизуйтесь в `https://inv.pak-cspmz.ru/` и оставьте хотя бы одну вкладку GLPI открытой.

Для разовой сверки запустите **Инструменты → GLPI Inventory: сверить всех (dry-run)**. Очередь продолжит работу после перезапуска TSHelper. Результаты доступны через **GLPI Inventory: результаты сверки**.

Ход проверки виден в **Инструменты → GLPI Inventory: живой монитор**: там отображаются текущий пользователь, стадия парсинга, связь с расширением и последние результаты. В полном отчёте можно выбрать конкретного пользователя и нажать **Проверить выбранного сейчас**.

## Безопасность и правила сопоставления

- расширение использует только cookies текущей GLPI-вкладки и не читает/не сохраняет пароль;
- HTML и cookies не передаются TSHelper: локальный bridge получает только нормализованные User/Computer ID, hostname, ОС, статус, serial и inventory number;
- пользователь считается найденным только после проверки точного `login` в форме GLPI User;
- компьютеры удалённого доступа с префиксами `lr-` и `wr-` исключаются из результата и не передаются в карточку TSHelper;
- автоматическое изменение карточки разрешено только для одного активного Computer;
- несколько компьютеров, отсутствие пользователя и ошибки сессии попадают в отчёт без автоматической правки;
- загрузка заголовков и полного HTML-тела ограничена общим таймаутом; одна зависшая карточка не может удерживать очередь дольше 35 секунд;
- локальный HTTP-сервер слушает loopback и требует случайный токен TSHelper.

## Диагностика

Если очередь не движется, проверьте по порядку:

1. TSHelper запущен, статус browser bridge — «работает».
2. В настройках расширения проверка соединения успешна.
3. Вкладка GLPI открыта и сессия не истекла.
4. В TSHelper в статусе очереди нет постоянного `session_required`.

Расширение рассчитано на текущую установку GLPI `inv.pak-cspmz.ru`. При изменении домена его нужно добавить в `host_permissions` и `content_scripts.matches` файла `manifest.json`.
